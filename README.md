# Travel Planner Pro 🌎

Travel Planner Pro is a web application that helps users plan trips by combining country information, weather forecasts, and upcoming events in one place.

The application allows users to search for a destination and view useful travel information before planning their trip.

## Features

### Country information
- Country name
- Country flag
- Region
- Population
- Currency
- Languages


### Weather Forecast
- 3-day weather forecast
- Weather conditions
- Temperature
- Humidity
- Chance of rain
- UV index
- Wind speed


### Events
- Search upcoming events by city
- Event date and time
- Venue information
- Indoor/outdoor event category
- Ticket purchase links
